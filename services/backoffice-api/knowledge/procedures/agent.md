## Signes typiques
- Retraits chez un agent que le client n'utilise pas d'habitude, parfois dans une autre province.
- L'agent opère avec le PIN du client depuis sa propre ligne, ou directement sur le téléphone que le
  client lui a confié pour l'aider (clients peu familiers du service).
- Plusieurs clients différents touchés par le même agent sur une courte période.

## Vérifications
- Le client était-il physiquement présent chez l'agent ? A-t-il confié son téléphone ou son PIN ?
- Autres dossiers et alertes récents sur le même agent ; volume inhabituel de clients sur 24 h.
- Informer le superviseur du réseau de distribution de la zone (sans alerter l'agent).

## Mesures
- Escalade obligatoire au superviseur : une fraude d'agent implique souvent plusieurs victimes.
- Suspension préventive de l'agent décidée par le responsable du réseau, pas par l'analyste seul.
- Rembourser les clients victimes selon la politique de l'opérateur une fois la fraude établie.

## Éléments à décharge
- Client en déplacement qui confirme le retrait ; agent sans autre incident ; montant habituel.
